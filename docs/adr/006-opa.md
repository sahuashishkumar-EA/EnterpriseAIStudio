# ADR-006: OPA on Cloud Run with a Python mirror for tests

Status: accepted, 2026-11-19

## Context

GCP has no managed OPA; the build session and unit tests have no OPA binary.

## Decision

Run OPA as an internal Cloud Run service (`EAP_OPA_URL`), policies from `policies/` (later a GCS bundle). `eap_workflow.policy.LocalPolicy` mirrors the Rego rules for tests. Backlog: add `opa test policies/` and a Rego-vs-mirror parity test to Cloud Build.

## Consequences

Two copies of each rule must be kept in step until the parity test exists.
